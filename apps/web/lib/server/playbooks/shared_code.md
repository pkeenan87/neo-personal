# Playbook: shared_code — "I shared a code"

Use when the person read out or forwarded a one-time code (text, email, or app prompt) to someone. The code usually lets the other person sign in, reset a password, add a device, or approve a payment. Ask which service the code came from (the text usually names it) and how long ago it was shared.

## First, right now
1. Open the real app or website for that service and sign in. If you cannot, use its "forgot password" or account recovery straight away.
2. Change the password and choose "sign out of all other devices" if offered.
3. If the code was from a bank, card, or payment app (Zelle, PayPal, Cash App, Venmo), call the number on the back of your card or use the in-app support and tell them a code was shared.
4. If the code was for WhatsApp, Signal, or another messaging app, re-register the app on your phone now; that kicks the other person off.

## Then
- Check the account for changes: new devices, new email or phone number on the account, new recovery options, new payees, and remove anything you did not add.
  - Google: https://myaccount.google.com/security-checkup.
  - Apple: devices and trusted numbers at https://account.apple.com.
  - Microsoft: https://account.live.com/Activity.
- Turn on stronger two-step verification (authenticator app or passkey) and set a PIN or registration lock in messaging apps.
- If the code came from the phone carrier, call the carrier from another phone or visit a store and ask whether a SIM swap or number port was requested; ask for a port-out PIN.
- Warn close contacts if a messaging or social account was taken over, so they ignore requests for money.

## Report
- The message that asked for the code: forward texts to 7726; report email as phishing in the mail app.
- Losses or account takeover: https://reportfraud.ftc.gov (US) and https://www.ic3.gov.
- Outside the US: their country's consumer protection agency.

## What to watch for next
- More codes arriving that they did not request: someone is still trying. Never share them; codes are only ever typed into the real app by you.
- People claiming to be the service ("we sent you a code by mistake, please read it back"). No real company asks for a code it sent.
- Friends reporting odd messages from the account.

## Reassurance
A shared code is usually only good for a few minutes and for one action. Signing in, changing the password, and signing out other devices undoes most of what it allowed. Checking now is the right call.

# Playbook: clicked_link — "I clicked a link"

Use when the person opened a link from a suspicious email, text, social media message, or pop-up. Find out quickly: did they only open the page, or did they also type something (password, card, code) or download/install something? If they typed a password, also follow entered_password. If they installed an app or let someone connect, also follow device_compromised.

## First, right now
1. Close the page or tab. Do not type anything more into it, and do not call any number or reply to any chat it shows.
2. If a file downloaded, do not open it. Delete it from Downloads (on a phone, do not install anything it asks for).
3. If they entered a password, card number, or code on that page, say so now: those steps come first (change the password on the real site, or call the number on the back of the card).
4. If a scary pop-up says the device is locked or infected, it is almost always fake. Close the browser; on a computer, restart it if the page will not close.

## Then
- Only opened the page: in most cases nothing else is needed. Clear the browser's recent history and site data for that day if they want peace of mind.
- Check that the browser and operating system are up to date (Settings → Software Update on iPhone/iPad and Mac; Settings → System → Software update on Android; Windows Update on a PC). Updates close the holes that malicious pages rely on.
- On a computer, run the built-in scan: Microsoft Defender on Windows (Windows Security → Virus & threat protection → Quick scan). Macs scan automatically; keeping macOS updated is the main step.
- Review browser extensions and remove anything they do not recognize.
- If they are not sure what they typed, check their important accounts for new sign-ins: Google Security Checkup (https://myaccount.google.com/security-checkup), Apple Account devices (https://account.apple.com), Microsoft recent activity (https://account.live.com/Activity).

## Report
- Suspicious text message: forward it to 7726 (spells SPAM on the keypad), then delete it.
- Email: use "Report phishing" in Gmail or Outlook, or forward Apple-themed scams to reportphishing@apple.com.
- The web page itself: report it to Google Safe Browsing at https://safebrowsing.google.com/safebrowsing/report_phish/.
- Anything that cost money or data: FTC at https://reportfraud.ftc.gov (US). Outside the US, their country's consumer protection agency (UK: Action Fraud; Canada: Canadian Anti-Fraud Centre; Australia: Scamwatch; EU: national consumer or police cybercrime service).

## What to watch for next
- Follow-up messages that reference the first one ("we noticed you visited…", "your refund is ready"). Same sender tricks, second attempt.
- Calls from someone claiming to be the bank or "fraud department" asking them to confirm codes or move money. Real banks never ask for a code they sent you.
- Unexpected password-reset emails or sign-in alerts over the next few weeks: check them in the real app, never through links in the alert.

## Reassurance
Opening a link on an up-to-date phone or computer very rarely installs anything by itself. The danger is almost always what a page asks you to type or download, and closing it stops that. Lots of careful people click links like this; noticing and asking is exactly the right move.

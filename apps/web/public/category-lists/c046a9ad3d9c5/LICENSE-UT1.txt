The data has been converted to a compact format and filtered; no endorsement by the licensor is implied. The adapted data in ut1-* files is distributed under the same licence.

Each ut1-*.bin file is a sorted list of 32-bit values (the first 4 bytes of the SHA-256 of a domain name, 4 bytes each, little-endian), derived from the UT1 category lists named in manifest.json. Entries were lowercased, stripped of comments and wildcards, limited to hostname-shaped lines and deduplicated, then hashed; the original domain names are not included. The ut1-social file also folds in data from The Block List Project (Unlicense); the combined file is distributed under CC BY-SA 4.0.
